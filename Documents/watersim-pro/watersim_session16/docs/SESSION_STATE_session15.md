## ✅ Session 15 — Advanced Reporting: History, Saved Reports, Scenario Comparison, Excel Export

### Scope
Three pillars:
1. **Report History & Saved Reports** — org-wide list of all completed simulation runs, bookmark/unsave, filter by project/mode/compliance, paginated.
2. **Scenario Comparison** — select 2–6 runs, side-by-side comparison of effluent quality, removal efficiencies, and costs with "best value" highlighting.
3. **Excel Export** — single-run multi-sheet workbook and multi-run comparison workbook, generated by Python (openpyxl) and streamed to browser.

### New Backend Files

#### `backend/src/db/migrations/003_saved_reports.js`
New `saved_reports` table:
```sql
saved_reports (
  id UUID PK, organisation_id FK, run_id FK, saved_by FK,
  label VARCHAR(255), notes TEXT, created_at,
  UNIQUE (organisation_id, run_id, saved_by)
)
```
Indexes on org+created_at, saved_by, run_id.

#### `backend/src/reports/excel_report.py`
Python/openpyxl Excel generator. Reads JSON payload from stdin, writes `.xlsx` bytes to stdout.

**Single run mode** (`{ "mode": "single", "data": reportData }`) — 4 sheets:
- **Summary**: metadata, compliance banner, violations, effluent quality table (PASS/FAIL per row), KPI strip.
- **Cost Breakdown**: category bar with % of total.
- **Unit Operations**: per-node metrics.
- **Warnings**: simulation warnings if any.

**Comparison mode** (`{ "mode": "comparison", "runs": [...] }`) — 3+ sheets:
- **Effluent Comparison**: all QUALITY_PARAMS as rows, one column per scenario; green highlights best effluent value per row.
- **Removal Efficiencies**: BOD/COD/TSS/TN/NH4/TP removal %, green = highest.
- **Cost Comparison**: OPEX rows, green = lowest cost/unit cost.
- **Legend**: explains all symbols.

Style conventions: Arial font, NAVY title bands, BRAND blue headers, emerald for best/pass, red for fail/over-limit, alternating gray row fills, all borders.

#### `backend/src/reports/excelGenerator.js`
Node.js wrapper (mirrors pdfGenerator.js). Spawns `python3 excel_report.py`, pipes JSON to stdin, resolves with Buffer of xlsx bytes. Error logs via logger.

#### `backend/src/routes/reports_org.js`
New router mounted at `/api/v1/reports`:

| Method  | Path                    | Auth    | Description |
|---------|-------------------------|---------|-------------|
| GET     | /reports                | any     | Paginated org run history. Query: page, limit, projectId, mode, compliance (pass/fail) |
| GET     | /reports/saved          | any     | All runs saved by current user |
| POST    | /reports/saved          | any     | Save/bookmark a run (body: runId, label?, notes?) — upserts |
| DELETE  | /reports/saved/:runId   | any     | Unsave a run |
| GET     | /reports/:runId/excel   | any     | Export single run as .xlsx — streams file download |
| POST    | /reports/compare/excel  | any     | Export 2–6 runs as comparison .xlsx (body: runIds[], labels[]) |

All routes verify org ownership via JOIN on projects.organisation_id.

### New Frontend Files

#### `frontend/src/pages/ReportsPage.jsx`
Full-featured report history & saved bookmarks page (`/reports`).

**Tabs**:
- **All reports** — paginated table of all org-wide completed runs.
- **Saved** — runs bookmarked by the current user.

**Report table columns**: Flowsheet/Project · Mode · Compliance · BOD removal · Unit cost ($/m³) · Completed · Actions (Save/Unsave, Excel, Open report). Columns progressively hide at sm/md/lg/xl breakpoints.

**Filters** (All tab): Project dropdown, Mode dropdown (steady/dynamic), Compliance dropdown (pass/fail/any). URL params kept in sync via `useSearchParams`.

**Selection for comparison**: checkboxes (up to 6). Floating `CompareBar` at bottom when 1+ selected — shows "Excel" and "Compare" buttons. Navigates to `/reports/compare?runs=id1,id2,...`.

**SaveModal**: label + notes textarea, upserts via `POST /reports/saved`.

**Excel download**: direct `fetch` with Bearer token, triggers browser download.

**Pagination**: prev/next with page X/Y display.

**Empty states**: tailored for All vs Saved tabs.

#### `frontend/src/pages/ComparisonPage.jsx`
Side-by-side scenario comparison (`/reports/compare?runs=...`).

Layout:
1. **Scenario header cards** (N columns): label, project, mode pill, compliance icon, violation count, editable label input, link to full report.
2. **Effluent Quality section**: all parameters as rows, N columns. Crown icon + green highlight on best (lower-is-better for pollutants, higher for DO). Red ↑ indicator for permit exceedances.
3. **Removal Efficiencies section**: BOD/COD/TSS/TN/NH4/TP removal %, TrendingUp + green on highest.
4. **Operating Cost Comparison**: if any run has cost data. TrendingDown + green on lowest OPEX / unit cost.
5. **Permit Compliance Detail** (collapsed by default): per-run violation lists with color-coded cards.

All sections collapsible. **Export Excel** button in sticky header calls `POST /reports/compare/excel` with current labels.

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Saved = bookmark not copy | Reference to run_id | No data duplication; run stays canonical |
| Saved label upsert | ON CONFLICT DO UPDATE | Re-saving updates label/notes cleanly |
| Comparison via URL params | `?runs=id1,id2,...` | Shareable/bookmarkable URL |
| Editable labels in comparison | Local state per session | Friendly names without DB write |
| Best-value highlighting | Green crown/arrow in comparison | Instantly scannable across many columns |
| Excel via Python/openpyxl | Same pattern as PDF | Node has no comparable xlsx library with full styling |
| 4-sheet single workbook | Summary + Cost + Units + Warnings | Engineering teams often share workbooks; keeps context together |
| Org-level history endpoint | Joins all org's projects | Engineers should see all runs, not just their own |
| Compliance filter | SQL JSONB boolean check | Avoids loading all rows client-side for filtering |

## Key API Call Examples

### List org run history
```
GET /api/v1/reports?page=1&limit=30&projectId=uuid&compliance=pass
```

### Save a report
```
POST /api/v1/reports/saved
{ "runId": "uuid", "label": "Baseline scenario", "notes": "Steady state at design load" }
```

### Export single run Excel
```
GET /api/v1/reports/uuid/excel
→ Content-Disposition: attachment; filename="watersim_Flowsheet1_abc12345.xlsx"
```

### Comparison Excel export
```
POST /api/v1/reports/compare/excel
{ "runIds": ["uuid1", "uuid2", "uuid3"], "labels": ["Baseline", "+BNR", "Full upgrade"] }
```
